# Candidato Antonio Ordones — CIPA Codevasf 2026/2027

Site estático da candidatura individual de Antonio Ordones à CIPA da Sede da Codevasf.

## Endereço oficial

https://ordonescodevasf.github.io/candidatura-cipa/

## Publicação no GitHub Pages

1. Abra o repositório `candidatura-cipa`.
2. Faça upload de **todo o conteúdo desta pasta**, preservando as pastas `assets/css`, `assets/js`, `assets/img` e `assets/docs`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)`.
5. Aguarde a publicação.

Não há `.github` nem `.nojekyll` neste pacote; portanto, não é necessário fazer upload de arquivos ocultos.

## Arquivos principais

- `index.html`: página publicada.
- `index-unico.html`: versão de teste com recursos visuais embutidos.
- `404.html`: fallback para GitHub Pages.
- `assets/css/app.css`: estilos.
- `assets/js/app.js`: interações, filtros, compartilhamento e contagem regressiva.
- `assets/img/antonio-ordones.webp`: retrato atualizado.
- `assets/img/flyer-candidatura.webp`: flyer atualizado com QR Code correto.
- `assets/img/marca-antonio.svg`: marca colorida.
- `assets/img/marca-antonio-branca.svg`: marca branca para fundo escuro, com “CIPA 2026/2027” visível.
